# Vendor: настройка меню

Раздел `/[locale]/owner/menu` использует существующие API категорий, позиций и настроек заведения.

- В меню отображается только выбранная слева категория. Категории и позиции можно перетаскивать; поиск и фильтры отключают изменение порядка позиций.
- Поиск работает в выбранной категории; в стоп-листе — по всем недоступным позициям. При смене категории поисковый запрос очищается.
- Переключатель категории меняет `is_active`, сохраняя `preorder_enabled`. Переключатель блюда меняет только `is_available`; остальные поля, включая КБЖУ, сохраняются.
- Стоп-лист включает отключённые блюда и все блюда отключённых категорий. Включение категории само по себе не включает отдельно отключённые блюда. «Включить все» восстанавливает оба уровня доступности; в карточке категории — только её позиции.
- Массовое включение выполняет запросы последовательно. При ошибке уже сохранённые изменения остаются, остальные можно повторить. Плановое включение по времени и модификаторы блюд не добавлены: их нет в текущей модели.
- Редактор категорий расширяет левую колонку. Доступность и предзаказ расположены отдельными подписанными строками. Создание категории доступно через «+» вне режима настроек и открывает только новую категорию.
- Карточка фотографий показывает долю позиций с фото и включает фильтр позиций без фото.
- Создание и редактирование блюда открываются в боковой панели. Сохранение применяет название, категорию, описание, цену, фото, доступность, отметку «Хит», вес и КБЖУ. Закрытие без сохранения отменяет черновик.
- Титульное фото сохраняется в `venue.settings.cover_image_url`, общей обложке публичной страницы Dish. Перед записью читаются актуальные настройки, чтобы сохранить другие поля. Допустимы JPG/PNG/WebP до 10 МБ; используется существующая обработка обложек.
- На телефоне колонки идут друг под другом, редактор занимает весь экран. Навигация и фирменные цвета Vendor сохранены.
